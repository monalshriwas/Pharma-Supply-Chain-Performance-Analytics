# Pharma Supply Chain Analytics

An **end-to-end pharmaceutical supply chain analytics project** built using **Python for data cleaning and exploratory data analysis (EDA)** and **Power BI for interactive dashboarding**.

This project **analyzed 200K+ shipment records** to uncover operational and financial insights related to **delivery performance, waste cost, demand trends, and revenue optimization**.

**Note:** Due to GitHub file size limitations, a 50K-row representative sample dataset was uploaded. The full analysis and dashboard were built on 200K+ records.
## Project Overview

This project focused on analyzing pharmaceutical supply chain operations to improve:

- On-time delivery performance
- Delay risk monitoring
- Waste cost reduction
- Product demand planning
- Revenue optimization
- Zone-level shipment analysis

The workflow covered the complete analytics lifecycle:

Raw Data -> Cleaning -> EDA ->KPI Analysis -> Dashboard -> Business Insights

## Key Insights

- Strong on-time delivery performance was maintained across most zones
- Delay hotspots were identified in selected regions
- Waste directly impacted profit margins
- High-demand SKUs drove major revenue contribution
- Certain products contributed disproportionately to waste cost
- Zone-level optimization opportunities were identified

## Recommendations

- Delivery routes in high-risk zones should be optimized
- Inventory and cold-chain monitoring should be strengthened
- Stock planning for high-demand products should be prioritized
- Waste-prone SKU overstocking should be reduced
- Demand forecasting should be improved to minimize loss
- Zone-level logistics bottlenecks should be monitored regularly
